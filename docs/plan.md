# Plan

## Kinds of work

- **Foundation.** Setup that every feature stands on. Done when it runs
  locally and in the Codespace, and the tests and linters pass.
- **Feature.** Something a visitor can see or do. Done when it works in
  the demo and has a test.

## Blocks

- **Skeleton.** Foundation. Status: in review. The FastAPI app, htmx,
  Tailwind theme, fonts, tests and Codespace config.
- **The build.** Feature. Status: not started. Decided live.

## The build, in steps (each needs Michael's OK)
1. **Cards.** Notes data, status rules, sorted cards, 1:55 tests.
2. **Add note.** Append a note, cards re-sort (for the 7:10 twist).
3. **Ask + route.** Request box produces the instruction and the request, with Send logging them as notes.
4. **Submit.** README, title and one sentence, commit by 7:30.
